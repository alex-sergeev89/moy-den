# Моя жиза — установка на iPhone

Папка `moy-den-app` — это готовое автономное веб-приложение. Его нужно один раз
выложить в интернет (бесплатно, на GitHub Pages), а затем добавить на главный
экран iPhone. После этого оно открывается как обычное приложение, работает
офлайн и хранит данные на телефоне.

## Шаг 1. Выложить на GitHub Pages (10 минут, один раз)

1. Зайдите на https://github.com и войдите или создайте аккаунт.
2. Нажмите «+» в правом верхнем углу → **New repository**.
   - Repository name: `moy-den`
   - Public
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file**
   (ссылка в тексте) или **Add file → Upload files**.
4. Перетащите в окно **содержимое** папки `moy-den-app`:
   `index.html`, `manifest.webmanifest`, `sw.js` и `README.md`
   (иконки встроены в страницу, папка `icons` не нужна). Важно: файл `index.html` должен лежать в корне репозитория, а не
   внутри папки `moy-den-app`.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages** (в левом меню). В разделе **Build and
   deployment** выберите Source: **Deploy from a branch**, Branch: **main**,
   папка **/ (root)**, нажмите **Save**.
7. Через 1–2 минуты вверху страницы Pages появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/moy-den/`. Откройте его в браузере и убедитесь,
   что планировщик загрузился.

## Шаг 2. Поставить на iPhone

1. Откройте адрес из шага 1 в **Safari** на iPhone (именно Safari, не Chrome).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой внизу экрана).
3. Выберите **«На экран "Домой"»** и нажмите **Добавить**.
4. На главном экране появится значок «Моя жиза». Открывайте его как обычное
   приложение: без адресной строки, на весь экран, работает без интернета.

## Шаг 3. Включить ИИ-тренера (по желанию)

Робот Тренер и оценка калорий работают через нейросеть на выбор. Выбор и ключи
задаются в приложении по кнопке **«Настроить ИИ»** и хранятся только на телефоне.

### Алиса AI (Яндекс)

Алиса AI доступна по API через Yandex Cloud. Сервис Яндекса не принимает запросы
напрямую из веб-страницы, поэтому между приложением и Алисой ставится маленькая
функция-посредник в вашем облаке. Её код лежит в файле `alice-relay/index.js`.

1. Зайдите на https://console.yandex.cloud с Яндекс ID и создайте платёжный
   аккаунт. Понадобится банковская карта; новым пользователям Яндекс обычно даёт
   стартовый грант.
2. В каталоге откройте **Сервисные аккаунты → Создать**. Имя: `moy-den-alice`,
   роль: `ai.languageModels.user`.
3. Откройте **Cloud Functions → Создать функцию**, имя `moy-den-alice`.
   - Среда выполнения: **Node.js 22**.
   - Вставьте содержимое файла `alice-relay/index.js` в редактор, файл назовите
     `index.js`. Создайте второй файл `package.json` с содержимым из
     `alice-relay/package.json`. Точка входа: `index.handler`.
   - Таймаут: **5 минут** (программа на неделю составляется около минуты). Память: 128 МБ.
   - Сервисный аккаунт: `moy-den-alice`.
   - Переменная окружения `APP_SECRET`: придумайте длинный код доступа и
     запишите его.
   - Нажмите **Сохранить изменения**.
4. На странице функции включите **Публичная функция** и скопируйте
   **Ссылку для вызова** вида `https://functions.yandexcloud.net/…`.
5. В приложении: **Настроить ИИ → Алиса AI (Яндекс)**, вставьте ссылку в поле
   «Адрес функции» и код из переменной `APP_SECRET` в поле «Код доступа».

Запросы оплачиваются с платёжного аккаунта Yandex Cloud. Код доступа защищает
функцию: без него посторонний не сможет тратить ваши деньги, поэтому не
публикуйте его.

### Claude (Anthropic)

1. Зайдите на https://console.anthropic.com, создайте аккаунт и пополните
   баланс (это отдельно от подписки Claude).
2. В разделе **API Keys** создайте ключ и скопируйте его.
3. В приложении: **Настроить ИИ → Claude (Anthropic)**, вставьте ключ и
   выберите модель.

## Что умеет тренер

- **Программа тренировок** на неделю или месяц по вашим параметрам, подготовке
  и регулярным тренировкам. Упражнения отмечаются галочками, кнопка
  «Завершить» записывает тренировку в журнал.
- **Журнал и контроль**: таблица за 14 дней (тренировка, вода, калории, вес),
  пометки «выполнено», «частично», «пропуск», кнопка «Отчёт тренера».
- **Меню на день**: что и сколько съесть в каждый приём, с кнопками
  «Съел, записать» и «Заменить».
- **Робот Секретарь** (вкладка «Дела»): принимает поручения обычным текстом,
  например «завтра в 13:30 суд, напомни за час» или «перенеси встречу на
  пятницу». Сам создаёт, переносит и отмечает дела, следит за накладками и
  просроченным. Его изменения отменяются одной кнопкой. Блок «Планы на 7 дней»
  показывает ближайшие дела, кнопка «В Календарь iPhone» передаёт их в
  Календарь с напоминаниями.
- **Секретарь спрашивает сам**: утром и вечером задаёт вопрос о новых делах и
  напоминаниях, а после добавления дела со временем спрашивает, за сколько
  напомнить.
- **Почта**: вкладка «Ещё», блок «Почта для секретаря». Поддерживаются Gmail,
  Яндекс Почта и Mail.ru, можно подключить несколько ящиков сразу. Нужен пароль приложения, не основной пароль от почты.
  Секретарь читает только новые непрочитанные письма за три дня, ничего не
  помечает и не удаляет, кратко пересказывает почту и предлагает дела, которые
  вы подтверждаете кнопкой «записать».
- **Итоги дня**: каждый вечер после 21:00 приложение проводит анализ дня:
  оценка, что получилось, что упущено, три шага на завтра. Время меняется в
  блоке «Итоги дня».
- **Разбор дня**: каждое утро тренер сам обдумывает режим (сон, дела,
  тренировку, питание, воду) и даёт план по часам. Пункты плана одним
  нажатием переносятся в расписание. Автоматический разбор отключается
  галочкой в блоке «Тренер о вашем дне».
- **Сон**: время отбоя и подъёма, качество сна, цель, недосып за неделю,
  кнопки «Ложусь спать» и «Проснулся», напоминание об отбое.
- **Напоминания** о воде, еде и отбое. Открытое приложение показывает их вверху
  экрана. Чтобы телефон напоминал и при закрытом приложении, нажмите
  «Добавить в Календарь iPhone» в блоке «Напоминания»: веб-приложения на
  iPhone не могут сами отправлять уведомления по расписанию.

## Данные и резервные копии

- Все записи хранятся в памяти приложения на телефоне. Если удалить значок с
  главного экрана, записи пропадут.
- Вкладка «Ещё», блок «Резервная копия»:
  - **Сохранить копию в «Файлы»** открывает меню «Поделиться», в нём выберите
    «Сохранить в Файлы».
  - **Скопировать копию** кладёт копию в буфер обмена. Её можно вставить в
    «Заметки» или сразу в другое приложение «Моя жиза».
  - **Восстановить из файла** и **Вставить скопированную копию** возвращают
    данные.
- Коды доступа ИИ в копию не попадают, их нужно ввести заново.

## Обновление приложения

Когда появится новая версия, замените файлы в репозитории на GitHub
(Add file → Upload files, перетащить новые файлы, Commit changes).
Телефон подхватит обновление при следующем открытии с интернетом.
Если хотите пересобрать приложение из основной страницы самостоятельно,
запустите в папке проекта:

```bash
python3 build-app.py
```
